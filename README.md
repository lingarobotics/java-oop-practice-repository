# Java Practice

A personal repository documenting my practical Java OOP learning journey.

## Why This Repository Exists

This repository exists to showcase the **OOP concepts I learn through my course and how I translate those concepts into Java code by writing the programs myself**.

Rather than keeping the learning only as theory, I use this repository to demonstrate my understanding through actual implementations.

## How It Happens

For each OOP concept or practice task, I create a class and implement the exercise myself.

The `Main` class is used to run and test the code written for each practice exercise.

As I learn new concepts, more classes and exercises will be added to the repository.

## What It Shows

This repository demonstrates how I translate the **OOP concepts learned from my course into working Java code**.

It reflects my practical understanding and ability to apply concepts such as:

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- And other OOP concepts as I progress through my learning journey

The code in this repository is written as part of my learning process and represents my own practice and implementation.
